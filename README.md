# Nor-Dar Dance Ensemble

Готовый статический сайт на Astro, Tailwind CSS и Decap CMS.

## Запуск

```bash
npm install
npm run dev
```

Сайт откроется на локальном адресе, который покажет Astro.

## Админка

Админка доступна по адресу:

```text
/admin/
```

Для локального сохранения контента через Decap CMS запустите рядом с dev-сервером:

```bash
npm run cms
```

После этого новости, мероприятия, галерея, видео, программы и настройки будут редактироваться как файлы в `src/content` и `public/uploads`.

## Добавить новость

Откройте `/admin/`, выберите раздел `Новости`, нажмите `New Новости`, заполните заголовок, дату, обложку, краткое описание и текст. После сохранения появится Markdown-файл в `src/content/news`, а страница новости будет доступна по slug.

## Сборка для Hostinger

```bash
npm run build
```

Готовые файлы появятся в папке `dist`. Содержимое этой папки можно загрузить в `public_html` на обычном статическом хостинге.
